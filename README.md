# Hanoi Study Timer (หอคอยฮานอย · จับเวลาอ่านหนังสือ)

ตัวจับเวลาอ่านหนังสือ/ทำงาน ที่ย้ายวงแหวนระหว่างเสา A, B, C ตามอัลกอริทึม Tower of Hanoi
เปิดทิ้งไว้ได้โดยไม่ต้องกดอะไร มี 3 โหมด: **ต่อเนื่อง** (Endless), **ตั้งเวลา** (Target Time), **คนยก** (Human Lifter)
มีโหมดเต็มหน้าจอ (เวลาแสดงอยู่ในฉาก) และธีมมืด/สว่าง/ตามระบบ

React 19 + TypeScript + Vite, วาดฉากด้วย SVG, ทดสอบด้วย Vitest

**เล่นได้ที่:** https://nopekka.github.io/hanoi-study-timer/ (deploy อัตโนมัติด้วย GitHub Actions ทุกครั้งที่ push ขึ้น `main` — รันเทสต์ก่อน build)

## วิธีรัน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิดที่ http://localhost:5173
npm run build      # ตรวจชนิดด้วย tsc แล้ว build ลง dist/
npm run preview    # เปิดไฟล์ที่ build แล้ว
npm test           # รัน unit test ทั้งหมด (Vitest)
```

ไฟล์ใน `dist/` ใช้ path แบบ relative จึงวางบนโฮสต์ static ใดก็ได้ (GitHub Pages ฯลฯ)
Wake Lock ทำงานเฉพาะบน HTTPS หรือ localhost

## หลักการทำงาน

- **ไม่เก็บรายการ Move**: วง d อยู่เสาไหนหลัง k Move คำนวณตรง ๆ ได้จาก
  `floor((k + 2^d) / 2^(d+1))` (จำนวนครั้งที่วง d ถูกย้าย) คูณทิศการวนของวงนั้น mod 3
  ส่วน Move ที่ k ย้ายวงหมายเลข `ctz(k)` (จำนวนบิต 0 ท้าย k) ดัชนี Move เป็น BigInt ทั้งหมด จึงใช้กับ n=64 ได้
- **เวลา**: เวลาที่ผ่านไป = เวลาสะสม + (`performance.now()` − เวลาที่เริ่มเดินรอบล่าสุด) ไม่บวกทีละเฟรม
  ตำแหน่งวงแหวนทุกเฟรมคำนวณจากเวลานี้ สลับแท็บแล้วกลับมาจึงตรงเสมอ
- **ลำดับใน 1 Move**: พักก่อนแล้วจึงขยับ วงสุดท้ายจึงวางลงพอดีกับวินาทีที่ครบเวลา
- **ตอนจบ**: ตรวจทุกเฟรม และตั้ง `setTimeout` ไว้ถึงเวลาจบด้วย เผื่อแท็บถูกซ่อน (rAF หยุด)
  เวลาที่บันทึกว่าเสร็จคือเวลาที่คำนวณได้ ไม่ใช่เวลาที่ตรวจเจอ
- **กดรัว ๆ**: Start/Resume ขณะเดินอยู่ไม่ทำอะไร loop และ timeout มีได้ชุดเดียวเสมอ (มีเทสต์)
- **กู้คืน**: บันทึกเซสชันเมื่อ Start/Pause/Resume/เปลี่ยนตัวคูณ, ทุก 15 วินาที และตอนซ่อน/ปิดหน้า
  หลังรีเฟรชจะมีแถบ "กู้คืน" ถ้าเซสชันกำลังเดินอยู่ตอนปิด เวลาที่ปิดไปจะถูกนับด้วย
- **ประหยัดแบต**: วาดเต็มอัตราเฟรมเฉพาะตอนมีของเคลื่อนที่ ช่วงพักวาด ~10 fps
  หยุดชั่วคราวแล้วไม่มี loop เลย (โหมดคนยกวาดทุกเฟรมตลอด เพราะตัวละครขยับอยู่เสมอ)
- **คนยกเคลื่อนต่อเนื่อง**: ยก–ขน–วางเป็นเส้นทางเดียวที่มีมุมโค้ง วงผ่านจุดเปลี่ยนขั้นตอนตรงเวลาโดยไม่หยุดกลางทาง
  ตัวละครเดินตามวงแหวน และพอเริ่มพักจะเดินไปยังเสาที่จะหยิบต่อด้วยความเร็วเดินปกติ แล้วยืนรอข้างวงพร้อมโยกตัวเบา ๆ
- **โหมดภาพเร่ง (10x ขึ้นไป)**: ทุกวงบินไปตำแหน่งจริงของมันตามเส้นทางปกติ ลงจอดแล้วถ้าตำแหน่งจริงเปลี่ยนก็บินต่อทันที
  วงเล็กบินเร็ว (0.22 วิ) วงใหญ่บินช้า (สูงสุด 0.48 วิ) ไม่มีวงไหนหายหรือโผล่ขึ้นมาเฉย ๆ
  วงแหวนเคลื่อนตามอัตราเฟรมของจอ ส่วนตัวเลขบนจอเปลี่ยนไม่เกิน 30 ครั้ง/วินาที
- **เต็มหน้าจอ**: ปุ่มมุมขวาล่างของฉาก, ปุ่ม <kbd>F</kbd> หรือดับเบิลคลิกที่ฉาก ใช้ Fullscreen API ถ้าเบราว์เซอร์ยอม
  ไม่งั้น (iPhone, หน้าที่ฝังแบบไม่อนุญาต) จะขยายเต็มหน้าต่างแทน ปุ่มบนฉากซ่อนเองหลังไม่ได้ขยับ 2.5 วินาที
  <kbd>Space</kbd> เริ่ม/หยุดชั่วคราว, <kbd>Esc</kbd> ออก
- **ธีม**: ปุ่มบนหัวเลือก ตามระบบ / มืด / สว่าง (จำไว้ใน localStorage) สีฉาก ไม้ และวงแหวนปรับตามธีม

## ค่าคงที่ (แก้ได้ที่ `src/config.ts`)

| ค่า | ค่าตั้งต้น |
| --- | --- |
| จำนวนวงแหวน (โหมดต่อเนื่อง) | 3–20 |
| ตัวคูณ | 1x, 2x, 5x, 10x, 50x, 100x, 1000x |
| เวลาต่อ Move ที่ 1x | 1 วินาที (ขยับ 0.8 วิ + นิ่ง 0.2 วิ) |
| เกณฑ์เข้าโหมดภาพเร่ง | มากกว่า 8 Move/วินาที (คือ 10x ขึ้นไป) |
| โหมดภาพเร่ง | เวลาบินต่อวง = 80% ของช่วงห่างระหว่าง Move ของวงนั้น (0.22–0.48 วิ), ตัวเลข ≤ 30 ครั้ง/วินาที |
| แอนิเมชันต่อ Move โหมดตั้งเวลา | 1.2 วิ (ยืดได้ถึง 2.5 วิ) |
| เวลาพักสูงสุดก่อนเริ่มยืดแอนิเมชัน | 6 วิ |
| ขั้นตอนคนยก | เดิน/เอื้อม 0.64 · หยิบ 0.4 · ยกขึ้น 0.56 · ขนไป 0.96 · วางลง 0.56 · กลับท่ายืน 0.48 = 3.6 วิ (เร็วขึ้น 20% จากสเปกเดิม 4.5 วิ ตามที่ขอ; ยืดได้ถึง 7.5 วิ ในสัดส่วน 2.5/1.2 เดียวกัน) |
| ปุ่มเวลาเป้าหมาย | 25 นาที, 45 นาที, 1, 2, 3 ชม. หรือกำหนดเอง 1 นาที – 12 ชม. |

ตัวอย่างที่ได้: 25 นาที → ตั้งเวลา 10 วง (1,023 Move, 1.47 วิ/Move) · คนยก 8 วง (255 Move, 5.88 วิ/Move = ยก 3.6 + พัก 2.28)

## การทดสอบ

`npm test` รัน 73 เทสต์ ครอบคลุม

- n=1 → 1, n=3 → 7, n=5 → 31 Move และ n=64 ด้วย BigInt
- ทุก Move ของ n=1–10 ถูกกฎ (ย้ายเฉพาะวงบนสุด ไม่วางใหญ่ทับเล็ก) และจบที่เสา C เรียงครบ
- ตำแหน่งที่คำนวณจากดัชนี Move ตรงกับคำตอบแบบ recursive ทุก Move ทุกสถานะ (n=1–10) และตรงกับสูตร bit trick
- Pause/Resume หลายรอบ เวลาและสถานะไม่คลาดเคลื่อน, แท็บซ่อนแล้วกลับมาสถานะยังถูก, กด Start รัวไม่เกิด loop ซ้ำ
- โหมด 2 และ 3: n ถูกต้องทุกนาทีตั้งแต่ 1 นาทีถึง 12 ชม., เวลาพักไม่ติดลบ, เวลารวมตรงเป้าหมาย,
  โหมด 3 ใช้เวลาต่อ Move มากกว่าและได้ n น้อยกว่า, กฎยืดแอนิเมชันเมื่อพักเกิน 6 วิ, กรณีเวลาสั้นเกินไป
- Estimated Completion ตรงกับเวลาจบที่ simulate จริงด้วยนาฬิกาปลอม (รวมกรณีหยุดกลางทาง)
- คนยกวางวงบนยอดเสาปลายทางตรงตำแหน่ง, มือจับขอบวงจริงตลอดช่วงยก, วงลอยพ้นยอดเสาทุกต้นระหว่างขน,
  ข้อต่อไม่สะบัดระหว่างเฟรม, ท่าจบ Move ต่อกับท่าพัก และท่าพักเสร็จต่อกับท่าเริ่มเดินของ Move ถัดไปพอดี,
  วงไม่หยุดกลางทางระหว่างยก–ขน–วาง และขยับออกด้านข้างได้เมื่อพ้นยอดเสาแล้วเท่านั้น
- โหมดภาพเร่ง: ไม่มีวงไหนกระโดดข้ามเสาในเฟรมเดียว (60 fps ที่ 10x/100x/1000x) และลงจอดตรงสถานะจริงเมื่อหยุด
- บันทึก/อ่านเซสชัน และปฏิเสธข้อมูลเสีย

## ข้อจำกัดที่เหลือ

1. **กฎ "พักเกิน 6 วินาทีให้ยืดแอนิเมชัน" ไม่เกิดขึ้นจริงกับค่าตั้งต้น** เพราะ n ที่มากที่สุดทำให้เวลาพักสูงสุดเพียง ~2.4 วิ (ตั้งเวลา)
   และ ~2.9 วิ (คนยก) โค้ดรองรับและมีเทสต์ด้วยค่าที่บังคับให้เกิด
2. **คำเตือน "เวลาเป้าหมายสั้นกว่า 1 Move" ไปไม่ถึงจาก UI** เพราะค่าต่ำสุดที่กรอกได้คือ 1 นาที ซึ่งพอเสมอ
   logic และข้อความเตือนมีอยู่และมีเทสต์
3. **แท็บที่ซ่อนอยู่**: เบราว์เซอร์หน่วง timer ของแท็บพื้นหลังเป็นราว 1 วินาที เสียงและสถานะ Completed จึงอาจช้าได้ถึง ~1 วินาที
   (เวลาเสร็จที่บันทึกยังตรง) ถ้าเครื่องเข้าโหมด sleep บาง OS/เบราว์เซอร์จะหยุดนับ `performance.now()` ระหว่างนั้น
4. **Wake Lock** ใช้ได้เฉพาะ HTTPS/localhost และเบราว์เซอร์ที่รองรับ ถ้าไม่ได้จะข้ามเงียบ ๆ
5. **เสียง** เล่นได้หลังผู้ใช้กดปุ่มเท่านั้น (นโยบาย autoplay) ถ้าเซสชันจบไปตอนหน้าปิดอยู่ จะไม่มีเสียงตอนกู้คืน แต่แสดงเวลาที่เสร็จจริง
6. **ภาพโหมดภาพเร่ง** ไม่แสดงทุก Move: ภาพตามหลังสถานะจริงไม่เกินเวลาบิน 1–2 รอบ (≤ ~1 วิ) และที่ 1000x วงเล็กราว 8 วงจะบินวนอยู่ตลอด
   ระหว่างบินวงอาจซ้อนกันชั่วครู่ ตัวเลข Move ยังนับครบทุก Move
7. **ตัวละครคนยกเป็นภาพ 2D มุมหน้า** ใช้ IK แบบง่ายที่ย่อความยาวแขน/ขาเมื่อชี้เข้าหาผู้ชม กระดูกยืดได้ไม่เกิน ~7% ตอนเอื้อมสุด
   ระหว่างพักตัวละครเดินไปรอที่เสาถัดไปแล้วโยกตัวเบา ๆ (สเปกเดิมให้ "ยืนนิ่งหรือขยับเบา ๆ") โหมดคนยกวาดทุกเฟรมตลอด
   ตัวนับ Move ของคนยกเพิ่มเมื่อจบท่ากลับท่ายืน (0.48 วิ หลังวงวางลง)
8. ฟอนต์โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ไทยของระบบแทน ยังไม่ทำเป็น PWA ติดตั้งแบบออฟไลน์
10. **เต็มจอบน iPhone** ไม่มี Fullscreen API สำหรับ element จึงเป็นแบบเต็มหน้าต่าง (ยังเห็นแถบที่อยู่ของเบราว์เซอร์)
    ในหน้าที่ฝังแอปไว้ (เช่น Artifact) บางที่ไม่อนุญาตเต็มจอจริง จะใช้แบบเต็มหน้าต่างเช่นกัน
9. เวลาคลาดเคลื่อน ≤ 1 วินาที และ Estimated Completion ยืนยันด้วยการ simulate นาฬิกาปลอมและทดลองในเบราว์เซอร์จริงแบบเร่งเวลา
   ไม่ได้เปิดรันจริงต่อเนื่อง 12 ชั่วโมง
